# Agentic Mechanics: Planning & Tool Use

Training materials for the UNDP Agentic AI & Vibe Coding program.

This repository contains a complete teaching package for one course module on how AI
agents plan tasks and use tools. It is designed so another trainer can pick it up and
deliver the session with little preparation.

## Contents

| Folder | What is inside |
|--------|----------------|
| `curriculum/` | The course outline, learning objectives, and glossary. Start here. |
| `slides/` | Presentation deck for the session. |
| `notebooks/` | Hands-on Jupyter notebooks learners run during the workshop. |
| `assignments/` | Exercises, solutions, and grading rubrics. |
| `resource-library/` | Annotated list of articles, papers, videos, and tutorials. |
| `assets/` | Diagrams, images, and sample data shared across materials. |

## How to use this package

1. Read `curriculum/OUTLINE.md` for the full session flow and objectives.
2. Present from `slides/`.
3. Run the notebooks in `notebooks/` in order during the hands-on sections.
4. Assign the work in `assignments/` and grade with the included rubrics.
5. Point learners to `resource-library/` for further study.

## Ready-to-open versions

Several materials have a polished, branded version you can open or share directly:

| File | What it is |
|------|------------|
| `slides/deck.pdf`, `slides/deck.pptx` | The presentation, exported from `slides/deck.md`. |
| `resource-library/library.html` | Interactive reading list: search and filter by topic, level, and access, with a pulled quote and link per source. |
| `curriculum/course-overview.html` | One-page overview with an interactive Full day / Half day / Multi-session schedule. |
| `assignments/workbook.html` | Learner workbook: a concept check with reveal-answer, exercises with collapsible solutions, and the rubric. |

These are generated from the Markdown sources in each folder and are branded for the UNDP
Istanbul International Center for Private Sector in Development (brand blue #0063AC, official
logo, prepared by Alan Al-Jammoor).
