Part 1 · Concept check (A0)

A short quiz on the ideas from the day. No coding. Answer in your own words, then reveal the answer.

Foundations

1. In one sentence, what is the difference between a chatbot and an agent?
Show answer
A chatbot answers or gives advice, while an agent takes action to get the task done, by planning and using tools, not just replying.
2. Name the four repeating steps of the agent loop.
Show answer
Goal, plan, act, observe (then repeat). Accept "plan, act, observe" with the goal as the starting input.
3. In the brain / hands / notebook / heartbeat analogy, the tools are the:
a) brain
b) hands
c) notebook
d) heartbeat
Show answer
b) hands. Tools are how the agent acts in the world.
4. True or false: an agent is conscious and thinks like a person.
Show answer
False. An agent is a loop run carefully, with a model choosing the next step.

Tool use

5. In the tool-use loop, who actually runs the tool: the model, or your code?
Show answer
Your code runs the tool. The model only asks for it.
6. A tool is described by three things. Name them.
Show answer
A name, a description, and the inputs it needs (its schema).
7. The model decides whether to use a tool mainly by reading the tool's:
a) name and description
b) hidden source code
c) file size
d) author
Show answer
a) name and description. The model never sees the hidden code.
8. Why is it useful for a failing tool to return a clear error message instead of crashing?
Show answer
A clear error tells the model what went wrong so it can fix its request and try again, instead of the whole program stopping.

Planning

9. Which planning pattern interleaves a thought and an action, step by step?
a) Chain of Thought
b) ReAct
c) Plan and Execute
d) Reflection
Show answer
b) ReAct.
10. The phrase "let us think step by step" is an example of which pattern?
Show answer
Chain of Thought.
11. In one sentence, what does reflection mean for an agent?
Show answer
The agent reviews its own answer and improves it if it is not good enough (make, judge, improve).
12. What is replanning, and when does an agent need it?
Show answer
Making a new plan when the world does not match the old one, for example when a tool fails or new information appears.

Putting it together

13. Give one example of a task where you should not use an agent.
Show answer
Any task a single prompt or a fixed script already handles, for example a simple one-off question with no steps that change. Accept reasonable examples.
14. Why is it worth checking the path an agent took, not just its final answer?
Show answer
A right answer can come from luck or bad steps. Checking the path shows whether the agent reasoned and chose tools sensibly, which matters for trust and for catching problems early.
15. Name the three things from the "practical trio" that you keep in check when running an agent.
Show answer
Cost, speed, and safety.

Part 2 · Hands-on exercises

A1 · Add a tool Notebook 1

Give an agent a brand new tool of your own and get it to use the tool. Start from 01_first_tool_use_loop_student.ipynb in Google Colab.

  • Add a new tool. A simple one: count the characters in a piece of text.
  • Write the tool definition (name, description, one input) and the Python function.
  • Add it to the tools list and run it when the model asks.
  • Ask a question that needs it, for example "How many characters are in the word 'development'?"
Show sample solution

One good answer. The learner adds a tool that counts characters.

text_length_tool = {
    "name": "text_length",
    "description": "Count how many characters are in a piece of text. Use this when the user asks how long a word or phrase is.",
    "input_schema": {
        "type": "object",
        "properties": {
            "text": {"type": "string", "description": "The text to measure."}
        },
        "required": ["text"],
    },
}

def run_text_length(text):
    return str(len(text))

tools = [calculator_tool, text_length_tool]

# In the loop, dispatch by tool name:
for block in response.content:
    if block.type == "tool_use":
        if block.name == "calculator":
            result = run_calculator(block.input["expression"])
        elif block.name == "text_length":
            result = run_text_length(block.input["text"])
        tool_results.append({"type": "tool_result", "tool_use_id": block.id, "content": result})

Grading: the tool is defined correctly, the agent actually calls it, and the learner can explain what happened.

A2 · Improve the multi-tool agent Notebook 3

Add a fourth tool and handle a mistake gracefully. Start from 03_multi_tool_agent_student.ipynb in Google Colab.

  • Add a fourth tool of your own, for example one that reverses a piece of text.
  • Wire it into both the tools list and the run_tool dispatcher.
  • Ask a fact that does not exist and watch the agent read the error and recover.
  • Ask three questions so the agent uses three different tools; read the Thought, Action, Observation lines.
Show sample solution

One good answer. The learner adds a tool that reverses text.

reverse_tool = {
    "name": "reverse_text",
    "description": "Return a piece of text reversed, back to front. Use this when the user asks to reverse or flip text.",
    "input_schema": {
        "type": "object",
        "properties": {
            "text": {"type": "string", "description": "The text to reverse."}
        },
        "required": ["text"],
    },
}

def run_reverse(text):
    return text[::-1]

tools = [calculator_tool, lookup_tool, greeting_tool, reverse_tool]

def run_tool(name, tool_input):
    if name == "calculator":
        return run_calculator(tool_input["expression"])
    if name == "lookup_fact":
        return run_lookup(tool_input["name"])
    if name == "greet_in_language":
        return run_greeting(tool_input["language"])
    if name == "reverse_text":
        return run_reverse(tool_input["text"])
    return "Error: unknown tool."

Grading: a new working tool wired into both places, sensible tool selection across questions, and a clear explanation of how the agent chose and recovered.

Part 3 · Capstone

Build a small agent end to end that plans, uses more than one tool, and gives a clear answer. Start from 05_capstone_student.ipynb. Pick one scenario, or design your own with your trainer.

Field data helper
Answer questions from a small program dataset, using a lookup tool and a calculator.
Multilingual FAQ assistant
Answer a few common questions and reply or greet in more than one language.
Report helper
Pull a few numbers from a small table and write a short plain-language summary.
Indicator calculator
Turn raw numbers (households, clinics) into simple program metrics.

Requirements

  • Runs from top to bottom without errors.
  • Uses at least two tools, each for the right request.
  • Uses the agent loop to plan across more than one step.
  • Handles at least one error or missing value without crashing.
  • Comes with a short written note: what it does, which tools and why, and one example of planning across steps.
