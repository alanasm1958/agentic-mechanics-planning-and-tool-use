Course Overview

Agentic Mechanics: Planning & Tool Use  ·  a beginner, hands-on training module

By the end of the day, every learner will have built a small AI agent with their own hands: one that decides what to do, uses tools to do it, checks its own work, and understands every part of how it works. No prior coding required.

What you will be able to do

1. Explain in plain words what makes a system an agent, and name the steps of the agent loop.
2. Describe what a tool is and follow a full tool-use loop, from request to result.
3. Describe the main planning patterns and pick one that fits a task.
4. Run and lightly modify a small agent that plans, uses tools, and recovers from a mistake.
5. Judge when an agent is the right choice, and talk sensibly about cost, safety, and evaluation.
