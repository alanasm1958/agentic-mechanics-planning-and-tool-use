# Assignments

Exercises for learners, with solutions and a grading rubric. They are written
for beginners and map directly onto the notebooks and the course outline.

## What is here

| File | Type | Tied to |
|------|------|---------|
| `A0_concept_check.md` | Short quiz on the ideas | Parts A to D |
| `A1_add_a_tool.md` | Guided coding task | Notebook 1 |
| `A2_improve_multi_tool_agent.md` | Guided coding task | Notebook 3 |
| `capstone.md` | Open-ended project plus rubric | Notebook 5 |
| `solutions/` | Answer key, sample solutions, grading rubric | all of the above |

## How to use these

- **A0** can be done on paper or in a document, before or after the hands-on parts.
- **A1 and A2** are done in Google Colab, starting from the matching student notebook.
- **The capstone** is a take-home project. Learners pick a scenario and build a
  small agent, then write a short note on how it plans and which tools it uses.

## Grading philosophy

This is a beginner course. The goal is understanding and a working result, not
polished engineering. Reward learners who get an agent to run, who can explain
what each step does, and who recover from errors. Partial credit is encouraged.
Sample solutions show one good answer, not the only answer.
