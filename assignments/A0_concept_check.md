# A0: Concept Check

A short quiz on the ideas from the day. No coding. Answer in your own words where
asked. The answer key is in `solutions/A0_answer_key.md`.

## Part A: Foundations

1. In one sentence, what is the difference between a chatbot and an agent?

2. Name the four repeating steps of the agent loop.

3. (Choose one) In the analogy where an agent has a brain, hands, a notebook, and
   a heartbeat, the **tools** are the:
   - a) brain
   - b) hands
   - c) notebook
   - d) heartbeat

4. True or false: an agent is conscious and thinks like a person.

## Part B: Tool Use

5. In the tool-use loop, who actually runs the tool: the model, or your code?

6. A tool is described by three things. Name them.

7. (Choose one) The model decides whether to use a tool mainly by reading the
   tool's:
   - a) name and description
   - b) hidden source code
   - c) file size
   - d) author

8. Why is it useful for a failing tool to return a clear error message instead of
   crashing?

## Part C: Planning

9. (Choose one) Which planning pattern interleaves a thought and an action, step
   by step?
   - a) Chain of Thought
   - b) ReAct
   - c) Plan and Execute
   - d) Reflection

10. The phrase "let us think step by step" is an example of which pattern?

11. In one sentence, what does **reflection** mean for an agent?

12. What is **replanning**, and when does an agent need it?

## Part D: Putting it together

13. Give one example of a task where you should **not** use an agent.

14. Why is it worth checking the **path** an agent took, not just its final answer?

15. Name the three things from the "practical trio" that you keep in check when
    running an agent.
